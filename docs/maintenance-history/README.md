# Completed maintenance scripts

This directory preserves one-time production repair scripts for incident
archaeology. They document what was changed and how safety checks worked at the
time. They are not supported commands, are not part of the active test suite,
and must not be rerun without a new incident review.

- `2026-w36-category-cuisine-repair.py.txt` — completed correction of W36
  recipe metadata and rendered output. The `.txt` suffix prevents accidental
  execution or import while preserving the original Python source.
